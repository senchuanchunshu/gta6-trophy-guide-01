An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: official names, descriptions and grades, a roadmap to the platinum, missable flags, a cited guide for every trophy, and a checklist that saves in the browser with export/import, kind filters and a spoiler setting. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network needed. Or serve `app/` with any static HTTP server.
